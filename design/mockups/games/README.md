# Games mockups

Source files for the FamilyHub Games Mockups design: https://claude.ai/artifact/4GW8Jr17Wm9SyhrWWu6hnB

Games at the wall: Word of the day, a five-letter word to find in six goes (boards A–D), and Number of the day, six numbers and a target to reach (boards E–H). All screens are 1920×1080, in the Day theme, using the sample Household's names. Ross and Sam are drawn in stand-in colours. The Hub uses each Member's real colour (see `notes.md`).
