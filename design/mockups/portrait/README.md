# Portrait mockups

Source files for the FamilyHub Portrait Mockups design: https://claude.ai/artifact/DALzVs9xQPJ5Asckhk9bch

The Hub on a screen mounted the tall way. **Parked:** kept for later, with the open questions in `notes.md`. All screens are 1080×1920, in the Day theme, with the sample Household and the same sample data as the landscape screenshot tests (08:15 on Wednesday 28 October 2026).

| File | Screen |
| --- | --- |
| `Main.dc.html` | A · Today, coming days as rows (five days) |
| `Grid.dc.html` | B · Today, coming days as a 2 × 2 grid (four days) |
| `Week.dc.html` | C · Week, a row per day (sketch) |
| `canvas.json` | Board layout and titles for the design canvas |
| `notes.md` | The options, a recommendation, open questions and what portrait means for the app |

The live artifact is the source of truth, as with the other mockups. The `.dc.html` files use the design tool's template syntax and need its runtime, so they don't open directly.
