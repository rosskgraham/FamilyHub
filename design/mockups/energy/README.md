# Energy mockups

Source files for the FamilyHub Energy Mockups design: https://claude.ai/artifact/Bc4q9HusqZVHkW77NC8U7H

An Energy Section and a Today view card for Intelligent Octopus Go: the price now, the next cheap time, when to run Hungry appliances, Live demand, and each day's House use and Car charging. All screens are 1920×1080, in the Day theme, with the sample Household and the same time as the screenshot tests (08:15 on Wednesday 28 October 2026). The rates and usage are made up.

| File | Screen |
| --- | --- |
| `Main.dc.html` | A · Energy on Intelligent Octopus Go |
| `Today.dc.html` | C · Today view with an Energy card |
| `canvas.json` | Board layout and titles for the design canvas |
| `notes.md` | How it works, where the data comes from, and what is still open |

The first design assumed the Agile tariff; it's in this folder's Git history. The live artifact is the source of truth, as with the other mockups. The `.dc.html` files use the design tool's template syntax and need its runtime, so they don't open directly.
