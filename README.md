# FamilyHub

A family wall display for the kitchen: a shared calendar, the weather, a shopping list (with Alexa voice add), YouTube, and a sleep mode woken by a motion sensor.

## Status

Early build. The Today and Week views run on a PC with sample data; see [`app/`](app/README.md). Hardware isn't chosen yet.
